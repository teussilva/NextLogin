# NextLogin

Sistema web de autenticação e gerenciamento de tarefas, com cadastro, login, dashboard e edição de perfil.

## ✨ Funcionalidades

- Cadastro e login de usuários
- Dashboard com gerenciamento de tarefas (criar, editar, excluir)
- Edição de perfil, incluindo foto
- Tema escuro
- API REST em Node.js + TypeScript

## 🛠️ Tecnologias

**Backend:**
- Node.js / TypeScript
- (adicione aqui: Express, banco de dados usado, etc.)

**Frontend:**
- HTML, CSS, JavaScript

**Testes:**
- Jest

## 🚀 Como rodar o projeto

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
Abra os arquivos HTML do frontend em um servidor local (ex: extensão Live Server do VSCode).

### Variáveis de ambiente
Crie um arquivo `.env` na pasta `backend` com as variáveis necessárias (ex: conexão com banco, chave JWT).

## 🧪 Testes

```bash
cd backend
npm test
```
